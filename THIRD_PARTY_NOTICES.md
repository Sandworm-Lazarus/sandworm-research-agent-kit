# Third-party components

Sandworm Research Agent Kit is original workflow, validation, CLI, fixtures and adapter code by Sandworm-Lazarus. It uses Pydantic AI as a dependency; it is not an official Pydantic project.

| Component | Version used | License | Source |
|---|---|---|---|
| Pydantic AI slim | 2.67.0 | MIT | https://github.com/pydantic/pydantic-ai |
| Pydantic | See requirements.lock | MIT | https://github.com/pydantic/pydantic |
| OpenAI Python client | See requirements.lock | Apache-2.0 | https://github.com/openai/openai-python |

The full installed dependency snapshot is recorded in `requirements.lock`. Each distributed package retains its own upstream notices and license. No upstream source code or model weights are vendored here. The `web/` viewer's assets and any additional notices are maintained in that directory or the root notices as applicable.
